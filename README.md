# Premium Dental Clinic

Site institucional responsivo da Premium Dental Clinic, em Simão Dias, Sergipe.

## Tecnologias
- React + TypeScript
- Vite
- CSS responsivo
- Lucide React

## Executar localmente
Requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

Para compilar a versão de produção: `npm run build`.
